## Structure type d'un bloc

Chaque dossier de bloc contient son propre `README.md` qui décrit :
- le contexte et la problématique ;
- les livrables (plan, code, capture ou vidéo de la solution en production, présentation) ;
- les instructions pour lancer le projet.

## Sécurité

Aucun mot de passe, clé d'accès ni fichier `.env` n'est publié dans ce dépôt.
